현재는 앱 소개·다운로드만 제공합니다.

이메일 구독 신청과 업데이트 메일 발송은 비활성화되어 있습니다. 다운로드에 이메일 입력이나 회원가입을 요구하지 않습니다.

1. 앱 기록은 컴퓨터에 저장됩니다

시간표·메모·할 일과 앱 설정은 사용자의 컴퓨터에 저장됩니다. 앱은 이 자료를 운영자·웹사이트·이메일 서비스로 자동 전송하지 않습니다. 앱에는 계정·분석·클라우드 동기화 기능이 없습니다.

내보낸 백업에는 개인 기록이 포함될 수 있습니다. 백업이나 화면을 다른 사람에게 보내면 해당 내용이 공유되므로 주의해주세요. 앱 기록과 로컬 백업 삭제는 사용자가 자신의 컴퓨터에서 관리합니다.

2. 이메일 구독은 운영하지 않습니다

현재 구독 양식은 입력·제출할 수 없으며, 확인 메일이나 업데이트 소식도 발송하지 않습니다. Brevo 이메일 연동과 Turnstile 보안 확인은 활성화하지 않았고 해당 보안 스크립트도 불러오지 않습니다.

향후 구독을 시작한다면 수집 항목·목적·보유 기간·처리위탁·국외 이전·구독 해지 및 삭제 절차를 먼저 안내하고 필요한 동의를 받겠습니다. 앱을 다운로드하거나 문의 이메일을 보냈다는 이유로 자동 구독 처리하지 않습니다.

3. 웹사이트 접속과 외부 다운로드

이 사이트는 Cloudflare를 통한 호스팅을 전제로 구성되었으며, 앱 파일은 GitHub Releases에서 제공합니다. 다운로드 버튼을 누르면 GitHub 및 그 파일 제공 서버로 이동할 수 있습니다.

외부 서비스는 접속 처리·보안 등을 위해 IP 주소, 요청 시각, 브라우저 정보 등의 접속 정보를 처리할 수 있습니다. 사이트에는 별도 방문 분석 스크립트나 광고 추적 도구를 넣지 않았지만, 이것이 호스팅·다운로드 서비스의 접속 기록까지 없다는 뜻은 아닙니다. 외부 서비스의 처리 지역·보유 정책은 해당 서비스 안내를 확인해주세요.
