베타 이용 안내

미슴도치 0.4.0은 베타 버전입니다. 앱 다운로드는 GitHub Releases에서 제공하며 이메일 구독은 아직 운영하지 않습니다.

지원 환경

현재 제공 파일은 Intel/AMD Windows 64비트와 Apple Silicon Mac용 ZIP입니다. 사용자 Windows PC에서 정상 작동 보고를 받았으나 모든 기기·운영체제 환경의 동작을 보장하지 않습니다. 로그인 자동 실행·잠자기 해제는 환경별 추가 확인이 필요합니다. Windows ARM·Mac Intel은 별도 패키지와 검증이 없습니다.

Windows에서는 전체 압축을 풀고 폴더 안 미슴도치.exe를 실행하세요. EXE만 따로 옮기지 마세요. Mac에서는 압축을 풀고 앱을 응용 프로그램 폴더로 옮겨 실행하세요.

베타와 보안 경고

기능·화면·저장 구조는 변경될 수 있습니다. 아직 개발자 인증서 서명·macOS 공증을 하지 않아 운영체제 보안 경고가 나타날 수 있습니다. 보안을 전역으로 끄지 마세요. 공식 다운로드 주소·배포 파일 체크섬을 확인하고 중요한 자료를 백업하세요.

기록과 업데이트

기록은 설치 폴더 밖에 저장됩니다. 업데이트 전에 앱에서 백업을 내보내고 종료하세요. 저장 구조가 바뀌는 버전은 호환성·변환 안내를 먼저 확인해야 합니다. 로컬 백업만으로 기기 고장·분실까지 막을 수는 없으므로 별도 백업도 권장합니다. 현재 앱은 새 버전을 자동으로 내려받아 설치하지 않습니다.

다운로드와 이메일

앱 다운로드에 회원가입·이메일 입력은 필요하지 않습니다. 이메일 구독 신청과 업데이트 메일 발송은 비활성화되어 있습니다. 향후 운영 시 별도 안내·동의 절차를 마련합니다.

외부 서비스와 자료

배포 파일은 미슴도치 GitHub Release에서 제공합니다. 앱 개인 기록은 그 저장소로 자동 전송하지 않습니다. 사진 아이콘은 원본과 사용 권한 확인 후 적용할 예정이며, 현재 웹페이지의 그림은 별도 임시 표시입니다.
